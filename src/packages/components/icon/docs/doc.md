## 图标

提供了一套常用的图标集合。

```vue demo
<template>
     <div class="md-icon-font">
        <l-icon icon="l-caidanlanwode" size="30" color="var(--color-input-text)"></l-icon>
    </div>
</template>
<script lang="ts">
</script>
```

### 属性

|属性	|说明	|类型	|可选值	|默认值|
|---- |----- |------ |---  |---- |
|color	| 图标色	| string	| - |	#a1a6b2 |
|size	| 图标大小	| string / number	| - |	22px |
